# Dudhaloy website mockup

Static design mockup for Dudhaloy (দুধালয়), the sweet shop of R.M. Dairy Farm & Agro Fisheries, Moulvibazar.

One page app: open `index.html`. Pages: home, sweet detail (`#sweet/<id>`), our farm (`#farm`), about us (`#about`), contact us (`#contact`).

Placeholders are highlighted in the page (prices, shop address/phone/WhatsApp/Facebook, sample reviews). Sweet photos are AI generated stand-ins.
